# Projeler
Nasıl Çalıştırılır?
Projenin çalıştırılması için visual studionun kurulu olması gereklidir.Projenin tüm dosyaları indirildikten sonra .sln dosyasına tıklandığında proje çalışır.
Sürüm Geçmişi:
At Yarışı Oyunu V1
-Form Tasarımları Eklendi
-Ön Sözleşme Eklendi
-Geçmiş Yarışlar Eklendi 
-Bakiye Sistemi Eklendi
At Yarışı Oyunu V2
-Ayak Mantığı Eklendi
-Gerçek Hayattaki Bahis Mantığı Eklendi
-At İstatistikleri Eklendi
-Oyundaki Bakiyenin Toplanıp Ganyan Oranına Göre Dağıtılması Eklendi(Para Havuzu)
